# 婚禮籌備清單：多人同步設定

```
瀏覽器 A ─┐                         ┌─ 每 5 秒問一次「有沒有新變更」
瀏覽器 B ─┼──► Apps Script ──► Google Sheet「進度」工作表
手機    ─┘   （需要同步密碼）
```

勾選、細項、負責人、備註都會存到 Google 試算表，其他人開著頁面大約 5 秒內會看到。
沒設定前（`SYNC_URL` 留空），頁面跟以前一樣只存在自己的瀏覽器。

## 1. 建立試算表與 Apps Script

1. [新增 Google 試算表](https://sheets.new)，取名例如「婚禮籌備清單同步」。
   （跟邀請函、LINE 小幫手那兩份分開）
2. 「擴充功能 → Apps Script」，把 `apps-script/Code.gs` 整份貼上，取代原本的程式碼，💾 儲存。
3. 上方函式選單選 `setup` →「執行」。第一次要授權：選帳號 →「進階」→「前往（不安全）」→「允許」。
   執行完，下方「執行記錄」會印出**同步密碼**，試算表右下角也會跳出提示。
   （之後重新整理試算表，也能在選單「💍 籌備清單同步 → 顯示同步密碼」看到）

## 2. 部署成網頁應用程式

1. 右上「部署 → 新增部署作業」→ 齒輪選「網頁應用程式」。
2. 執行身分：**我**；誰可以存取：**所有人**。
3. 部署後複製網址（`https://script.google.com/macros/s/.../exec`）。
   用瀏覽器打開，看到 `{"ok":true,...}` 就成功了。

## 3. 填進網頁

打開 `index.html`，找到 `SYNC_URL`，貼上網址後 push：

```js
var SYNC_URL='https://script.google.com/macros/s/xxxxxxxx/exec';
```

## 4. 開始同步

1. 打開規劃表，點上方「🔒 輸入同步密碼…」，輸入密碼。
   你原本存在瀏覽器裡的勾選紀錄會自動上傳。
2. 點最下面「複製同步連結」，把連結傳給另一半，對方打開就會自動帶入密碼。

## 注意

- repo 是公開的，網址放在網頁裡沒關係；**沒有同步密碼讀不到也改不了資料**。密碼不要放進 repo。
- 密碼外流的話，選單「🔄 更換同步密碼」，再把新密碼／新連結給另一半。
- 兩個人同時改**同一個欄位**時，最後存的人為準；改不同項目不會互相蓋掉。
- 斷線時改的內容會先存在瀏覽器，連上後自動補傳。
- 改了 Code.gs：「部署 → 管理部署作業」→ 鉛筆 → 版本選「新版本」→ 部署（網址不變）。
