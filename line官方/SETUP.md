# 婚禮 LINE 官方帳號小幫手：設定步驟

```
親友 LINE ──► LINE 官方帳號 ──(Webhook)──► Apps Script ──► Google Sheet（設定／座位表／推播…）
                                                     └──► 雲端硬碟（親友傳的照片）
```

## 功能一覽

| 功能 | 親友怎麼用 | 你們在哪裡管理 |
|---|---|---|
| 歡迎訊息 | 加好友自動收到 | 「設定」→ 歡迎詞 |
| 📅 婚禮資訊卡（含倒數天數） | 點選單「婚禮資訊」 | 「設定」→ 新郎、新娘、日期、時間、地點、地址、婚禮開始時間 |
| 🪑 查座位 | 點「查座位」→ 輸入名字；開放後直接打名字也行 | 「座位表」工作表 ＋「設定」→ 座位查詢開放／開放時間 |
| 🚗 交通停車 | 點「交通停車」 | 「設定」→ 交通資訊、停車資訊 |
| 💌 回覆出席 | 點「回覆出席」→ 開邀請函網站 | 「設定」→ 邀請函網址 |
| ✅ 出席狀態 | 點「出席狀態」→ 輸入姓名，確認有沒有收到回覆 | 「設定」→ 出席回覆試算表 |
| 💐 送上祝福 | 點「送上祝福」→ 打字；或直接傳「祝福 新婚快樂」 | 「祝福」工作表 |
| 📸 上傳照片 | 直接傳照片／影片進聊天室 | 雲端硬碟「婚禮照片（LINE）」資料夾 |
| 🖼 照片牆 | 婚禮現場投影，照片＋祝福即時輪播 | 選單「🖼 顯示照片牆網址」；「照片」「祝福」工作表可隱藏 |
| 📢 推播通知（含婚禮倒數 7 天／1 天） | — | 「推播」工作表 ＋ 試算表選單 |
| 好友名單、訊息紀錄 | — | 「好友」「訊息紀錄」工作表 |

---

## 1. 建立 LINE 官方帳號 ＋ 開啟 Messaging API

1. 到 [LINE Official Account Manager](https://manager.line.biz/) 用你的 LINE 登入 →「建立帳號」，
   帳號名稱例如「強尼 & ○○ 的婚禮」，類別隨意選（例如「個人／其他」）。
2. 進入帳號 → 右上「設定」→ 左側「Messaging API」→「啟用 Messaging API」。
   第一次會要你建立 Provider（名稱隨意，例如「Johnny Wedding」）。
3. 到 [LINE Developers Console](https://developers.line.biz/console/) → 剛剛的 Provider → 你的 Channel →
   **Messaging API** 分頁，拉到最下面「Channel access token (long-lived)」→ **Issue** → 先複製起來。

## 2. 建立試算表與 Apps Script

1. [新增 Google 試算表](https://sheets.new)，取名例如「婚禮 LINE 小幫手」。
   （建議跟出席回覆那份分開，兩個 Apps Script 才不會打架）
2. 「擴充功能 → Apps Script」，把 `apps-script/Code.gs` 整份貼上取代原內容，💾 儲存。
   再按左側「檔案」旁的 ＋ →「HTML」，檔名打 `Wall`（不用打 .html），把 `apps-script/Wall.html` 整份貼上，💾 儲存。
3. 上方函式選單選 `setup` →「執行」。授權：選帳號 →「進階」→「前往（不安全）」→「允許」。
   （會要求試算表、雲端硬碟、外部連線權限：分別用於寫資料、存照片、呼叫 LINE）
4. 回到試算表**重新整理**，上方會多一個「💍 LINE 小幫手」選單。
5. 選單「② 設定 Channel Access Token」→ 貼上步驟 1-3 的 token → 看到「✅ 已連線到官方帳號」就成功。

## 3. 部署成網頁應用程式

1. Apps Script 右上「部署 → 新增部署作業」→ 齒輪選「網頁應用程式」。
2. 執行身分：**我**；誰可以存取：**所有人** →「部署」。
3. 回試算表，選單「③ 顯示 Webhook 網址」，複製那整串（結尾有 `?key=...`）。

> `?key=` 是一組密碼：Apps Script 讀不到 LINE 的簽章，改用這個擋掉外人亂打。**這串網址別公開**。

## 4. 把 Webhook 接到 LINE

1. LINE Developers → Messaging API 分頁 → **Webhook URL** →「Edit」貼上 → 「Update」。
2. 打開 **Use webhook**。
3. 按「Verify」：若顯示 `302 Found` 之類的錯誤**可以忽略**（Apps Script 的正常行為），直接用手機傳訊息測試即可。
4. 回到 [Official Account Manager](https://manager.line.biz/) →「設定 → 回應設定」：
   - **Webhook：開啟**
   - **加入好友的歡迎訊息：關閉**（改用小幫手的歡迎詞，不然會收到兩則）
   - **自動回應訊息：關閉**（不然會跟小幫手搶著回）
   - 聊天：可以開著，你們仍能在 Official Account Manager 親自回覆。若想親自聊天不被打擾，把「設定」→ 看不懂的訊息回覆選單 改「否」。

### 測試

手機加官方帳號好友（Developers → Messaging API 分頁有 QR code）→ 應收到歡迎詞 → 傳「婚禮資訊」「查座位」試試。
沒反應的話看「訊息紀錄」工作表有沒有「錯誤」列。

## 5. 圖文選單（聊天室下方那排大按鈕）

已經做好圖：`richmenu/richmenu.png`（2500×1686，6 格）。

1. Official Account Manager →「主頁 → 聊天室相關 → 圖文選單」→「建立」。
2. 標題隨意；使用期間設到婚禮後；**選單列顯示文字**填「婚禮小幫手 💍」；預設顯示：**顯示**。
3. 「選擇版型」→ 大型的 **3×2 六格**。
4. 「上傳背景圖片」→ 選 `richmenu.png`。
5. 每一格動作選「**文字**」，依序填（文字要一字不差）：

   | A 左上 | B 中上 | C 右上 |
   |---|---|---|
   | `婚禮資訊` | `查座位` | `交通停車` |
   | **D 左下** | **E 中下** | **F 右下** |
   | `回覆出席` | `送上祝福` | `上傳照片` |

6. 儲存。（想改按鈕文字或配色：改 `richmenu/make_richmenu.py` 再執行 `python make_richmenu.py richmenu.png`）

## 6. 日常使用

### 改婚禮資訊
直接改「設定」工作表，**不用重新部署**，下一則訊息就生效。

### 座位表
- 「座位表」工作表每人一列：姓名、別名（例如「小明, Ming」，逗號分隔）、桌號、桌名／區域、備註。
  桌號填數字會顯示「第 5 桌」，填文字（例如「主桌」）就照原樣顯示。
- 一家人可以每人一列，或只列代表人並把其他人寫進別名。
- 先刪掉範例那列。
- **排好前把「座位查詢開放」維持「否」**；可以在「座位開放時間」填婚禮當天早上，時間到自動開放，不用當天手忙腳亂。
- 想附整張座位圖：把圖片放到任何 https 公開網址（例如邀請函的 GitHub Pages repo），貼到「座位圖網址」。

### 推播通知
1. 「推播」工作表新增一列：內容（可換行）、圖片網址（選填）。
2. 先點選那一列 → 選單「🧪 推播：選取列先只發給自己測試」
   （需先在「設定」填「管理員userId」：加好友後到「好友」工作表複製你自己那列的 userId）。
3. 確認 OK → 選單「📤 推播：發送目前選取的那一列」，會先顯示要發給幾人、剩多少額度再讓你確認。
4. **排程**：在「預定時間」填日期時間 → 選單「⏰ 開啟排程推播」，時間到（誤差 5 分鐘內）自動發送。

> ⚠️ **推播會扣訊息額度，回覆不會。** 推播一次 = 好友人數 則。
> 台灣免費方案（輕用量）每月額度很少（約 200 則，以 LINE 官方公告為準），好友 100 人就只夠推播 2 次。
> 選單「📊 查詢本月訊息額度」可隨時查。婚禮那個月若要多推幾次，可暫時升級「中用量」方案，婚禮後再降回來。
> 查座位、婚禮資訊、祝福這些都是**回覆**，不管多少人問都不扣額度。

### 照片
親友傳的照片／影片會自動存到你雲端硬碟的「婚禮照片（LINE）」，檔名含時間和傳送者名字。
LINE 傳的照片會壓縮；要原圖可請親友傳時選「原始畫質」。超過約 50MB 的影片可能存不下來。
不想開放：把「設定」→ 照片資料夾ID 清空。

### 出席狀態查詢
1. 打開邀請函那份「婚禮出席統計」試算表，複製瀏覽器網址列的網址。
2. 貼到這份的「設定」→ 出席回覆試算表。
3. 第一次要重新授權：Apps Script 編輯器選 `setup` →「執行」→ 允許（多了「讀其他試算表」的權限）。

親友輸入姓名後，會用邀請函表單填的「姓名」完全比對，同名多筆時顯示最新一筆。

### 婚禮倒數
1. 「設定」→ **婚禮開始時間** 填真正的日期時間（例如 `2027/5/1 12:00`）。
   婚禮資訊卡會自動顯示「⏳ 倒數 N 天」，這部分是回覆訊息，不扣額度。
2. 選單「⏳ 建立婚禮倒數推播」→ 在「推播」工作表加入婚禮前 7 天、前 1 天晚上 8 點的通知，並自動開啟排程。
   內容可以直接在工作表改，不想發就刪掉那列。⚠️ 這是推播，**會扣額度**（每則 = 好友人數）。
   想改天數或時間：改 `Code.gs` 最上面的 `COUNTDOWN_TEMPLATES`。

### 照片牆（婚禮現場投影）
1. 選單「🖼 顯示照片牆網址」→ 複製網址。
2. 婚禮當天用筆電打開（**用你自己的 Google 帳號登入的瀏覽器**），按 F11 全螢幕，接投影機或電視。
3. 左邊大圖每 7 秒換一張，新進來的照片會插隊先播並標「NEW」；右邊是加好友 QR code 和祝福留言捲動。
4. 每 15 秒自動抓新照片，不用重新整理。
5. **不想上牆的照片／祝福**：在「照片」或「祝福」工作表那一列的「照片牆顯示」填「否」，下一輪就不會出現。
   （建議婚禮當天請一位伴郎／伴娘用手機開著試算表幫忙把關）

> 照片牆網址也有一組密碼（`key=`），只給自己人，別貼到群組。
> 影片不會上牆，但一樣會存進雲端硬碟。

## 之後改了 Code.gs 怎麼辦？

「部署 → 管理部署作業」→ 鉛筆圖示 → 版本選「新版本」→ 部署。網址不變，LINE 那邊不用改。
（如果按成「新增部署作業」會產生新網址，就要回 LINE Developers 改 Webhook URL）
